# Домен dexichs.is-a.dev

Подключается в три шага. Первый и третий делаются в браузере — доступа туда у
меня нет.

## 1. Заявка на домен

Файл `dexichs.json` в этой папке — готовая заявка. Порядок:

1. Откройте https://github.com/is-a-dev/register и нажмите **Fork**.
2. В своей копии положите `dexichs.json` в папку `domains/`.
3. Откройте Pull Request в основной репозиторий.

Заявку принимают обычно за день-два. `is-a.dev` бесплатен и раздаёт домены
разработчикам — платить не нужно.

## 2. Файл CNAME — ТОЛЬКО ПОСЛЕ приёма заявки

Создайте в корне сайта файл `CNAME` с одной строкой:

    dexichs.is-a.dev

**Раньше времени класть его нельзя.** Проверено на себе: GitHub Pages
подхватывает файл немедленно и уводит сайт на домен, которого ещё нет — корень
начинает редиректить на страницу «этот домен свободен».

## 3. Включить домен в настройках

Когда PR примут (адрес начнёт откликаться):

1. Settings → Pages в репозитории `NijatMessenger`.
2. Custom domain → `dexichs.is-a.dev` → Save.
3. Дождаться галочки и поставить **Enforce HTTPS**.

Сертификат выпускается автоматически, обычно за четверть часа.

## Куда потом вписать адреса

В App Store Connect:

- Privacy Policy URL → `https://dexichs.is-a.dev/privacy.html`
- Support URL → `https://dexichs.is-a.dev/support.html`

До подключения домена работают адреса вида
`https://nijat7778889.github.io/dexichs/privacy.html` — их можно указать
сразу, а потом заменить.
