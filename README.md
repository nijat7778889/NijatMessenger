# NijatMessenger — прямая загрузка .ipa + установка через AltStore

Главная кнопка на странице — обычная ссылка `<a href="app/NijatMessenger.ipa"
download>`. Она не требует ни домена, ни deep-link'ов: при нажатии в Safari на
iPhone файл `NijatMessenger.ipa` физически скачивается на устройство (в
приложение «Файлы», обычно в «Загрузки»). Это проверено локально — файл
доходит до диска побайтово идентичным исходнику.

Дальше файл нужно один раз подписать/установить через **AltStore** — просто
скачанный `.ipa` сам по себе не ставит иконку на экран «Домой» (iOS не
запускает неподписанные пакеты). Порядок в UI (`index.html`, секция
`#install-steps`):

1. Скачать `.ipa` кнопкой на сайте (не требует домена — ссылка относительная).
2. Найти файл в «Файлы» → «Загрузки».
3. Поставить AltStore (если ещё не стоит) — altstore.io.
4. В «Файлах» открыть `.ipa` → «Поделиться» → «Скопировать в AltStore» (или
   AltStore → My Apps → «+» → выбрать файл из Файлов).
5. Один раз подтвердить доверие профилю: Настройки → Основные → VPN и
   управление устройством → профиль → «Доверять».

## Резервный вариант — источник AltStore (`source.json`)

В репозитории также лежит `source.json` — классический AltStore-source. Он
полезен, если вы хотите, чтобы AltStore видел приложение сразу в списке
источников (а не через ручной импорт файла). Ему **нужен реальный домен**,
потому что AltStore скачивает `source.json` и `.ipa` по абсолютным HTTPS-
ссылкам, а не через относительные пути сайта.

Чтобы включить этот вариант:

```bash
cd "NijatMessenger Direct install website"
find . -type f -name "*.json" \
  -exec sed -i '' 's#https://ВАШ_ДОМЕН#https://ИМЯ.github.io/РЕПО#g' {} +
```

Добавляется в AltStore через Sources → «+» → вставить
`https://ВАШ_ДОМЕН/source.json`, либо ссылкой
`altstore://source?url=https://ВАШ_ДОМЕН/source.json`.

## Частые ошибки

- **Файл открывается предпросмотром, а не скачивается** — в Safari зажмите
  кнопку и выберите «Скачать связанный файл».
- **После скачивания нет иконки на «Домой»** — это ожидаемо: `.ipa` нужно
  ещё открыть через AltStore (шаг 4), только тогда он подписывается и
  устанавливается по-настоящему.
- **«Ненадёжный разработчик»** — Настройки → Основные → VPN и управление
  устройством → профиль → «Доверять».
- **Приложение перестало запускаться через неделю** — нормально для
  бесплатного Apple ID в AltStore, откройте AltStore и нажмите «Refresh».

## Устаревший способ (itms-services / manifest.plist)

В репозитории всё ещё лежит `manifest.plist` от предыдущей схемы прямой
установки через `itms-services://` — она требовала `.ipa`, подписанный
валидным Distribution/Enterprise-сертификатом, и сейчас не используется на
странице. Можно удалить файл, если эта схема больше не понадобится.
