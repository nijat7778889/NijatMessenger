# NijatMessenger

Быстрый, приватный мессенджер для iPhone со сквозным шифрованием. Это
инструкция для тех, кто хочет **скачать и установить** NijatMessenger —
никаких технических знаний не требуется.

## Что нужно перед началом

- iPhone с iOS **16.0** или новее.
- Браузер **Safari** (другие браузеры на iPhone не подойдут для установки).
- Приложение **AltStore** — если его ещё нет, поставьте один раз по
  инструкции на [altstore.io](https://altstore.io).

## Как установить

1. **Скачайте файл.** Откройте сайт NijatMessenger в Safari на iPhone и
   нажмите кнопку **«Download .ipa»**. Файл `NijatMessenger.ipa` сохранится
   в приложение «Файлы».
2. **Найдите файл.** Откройте «Файлы» → «Загрузки» → `NijatMessenger.ipa`.
3. **Откройте его через AltStore.** Нажмите на файл → «Поделиться» →
   «Скопировать в AltStore» (или в самом AltStore: «My Apps» → «+» →
   выберите файл).
4. **Установите.** AltStore подпишет приложение вашим Apple ID и поставит
   его на экран «Домой».
5. **Подтвердите доверие (один раз).** Настройки → Основные → VPN и
   управление устройством → выберите профиль → «Доверять». После этого
   NijatMessenger открывается как обычное приложение.

## Частые вопросы

**Файл не скачивается, а открывается предпросмотром**
Зажмите кнопку «Download .ipa» и выберите «Скачать связанный файл» — Safari
сохранит его в «Файлы».

**Скачал файл, но иконки на «Домой» нет**
Так и должно быть — сам по себе `.ipa` ничего не устанавливает. Откройте его
через AltStore (шаг 3–4 выше), чтобы он подписался и появился на экране.

**AltStore просит войти в Apple ID**
Это нормально — так AltStore подписывает приложение лично для вас при
установке и при каждом обновлении.

**Пишет «Ненадёжный разработчик»**
Настройки → Основные → VPN и управление устройством → выберите профиль →
«Доверять».

**Приложение перестало открываться через неделю**
Это ограничение бесплатного Apple ID — подпись действует 7 дней. Откройте
AltStore и нажмите **Refresh**, чтобы переподписать приложение. Приложение
и все ваши данные при этом остаются на месте.

## Приватность

NijatMessenger использует сквозное шифрование для сообщений и звонков, не
показывает рекламу и не собирает данные о вас.
