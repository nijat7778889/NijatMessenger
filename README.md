# Сайт Dexichs

Ознакомительная страница мессенджера: что он умеет, как устроен и что известно
о человеке, который им пользуется. Приложение **отсюда не раздаётся** — ни файла
для установки, ни покупок здесь нет и быть не должно.

Живёт на GitHub Pages: <https://dexichs.is-a.dev/>

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | главная: как работает, что внутри, приватность, вопросы |
| `privacy.html` | политика конфиденциальности, русский и английский |
| `support.html` | поддержка и разбор жалоб, русский и английский |
| `styles.css` | всё оформление, включая обе текстовые страницы |
| `script.js` | переключение языка, появление разделов, полоска прочитанного |
| `assets/icons/` | иконка приложения и её цветные варианты |
| `assets/fonts/` | Golos Text и Martian Mono, латиница и кириллица отдельно |

## Как посмотреть у себя

```
python3 -m http.server 8765
```

Открыть <http://localhost:8765>. Открывать `index.html` двойным щелчком не
стоит: шрифты и переключение языка требуют настоящего адреса, а не `file://`.

## Языки

Русский лежит прямо в разметке, английский — словарём в `script.js`. Так
сделано нарочно: держать русский ещё и в словаре значит держать два источника
правды, которые однажды разойдутся. Добавляя текст на страницу, поставьте ему
`data-i18n="ключ"` и допишите тот же ключ в словарь `EN`.

## Чего здесь быть не должно

- ссылок на скачивание файла приложения;
- продажи чего бы то ни было, включая права администратора;
- обещаний, которых приложение не выполняет: страница описывает то, что уже
  работает, и по ней же будут сверять описание в App Store.
