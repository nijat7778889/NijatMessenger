# NijatMessenger

Быстрый, приватный мессенджер для iPhone со сквозным шифрованием. Это
инструкция для тех, кто хочет **скачать и установить** NijatMessenger —
никаких технических знаний не требуется.

## Что нужно перед началом

- iPhone с iOS **16.0** или новее.
- Браузер **Safari** (другие браузеры на iPhone не подойдут для установки).
- Apple ID — любой, в том числе бесплатный. Он нужен, чтобы подписать
  приложение лично для вас: без подписи iOS не запустит его.

## Способ 1. Через iLoader — без компьютера

Самый простой путь: всё делается на самом iPhone.

1. **Поставьте iLoader**, если его ещё нет — по инструкции с сайта iLoader.
2. **Скачайте файл.** Откройте сайт NijatMessenger в Safari на iPhone и
   нажмите **«Download .ipa»**. Файл `NijatMessenger.ipa` сохранится в
   приложение «Файлы».
3. **Найдите файл.** «Файлы» → «Загрузки» → `NijatMessenger.ipa`.
4. **Передайте его в iLoader.** Нажмите на файл → «Поделиться» → iLoader.
   Либо наоборот: откройте iLoader → **My Apps** → **+** → выберите файл.
5. **Установите.** iLoader подпишет приложение вашим Apple ID и поставит его
   на экран «Домой».
6. **Подтвердите доверие (один раз).** Настройки → Основные → VPN и
   управление устройством → выберите профиль → **«Доверять»**.

## Способ 2. Через AltStore — нужен компьютер

Дольше в настройке, но AltStore умеет обновлять приложение сам.

1. **Установите AltServer на компьютер** (Windows или Mac) по инструкции с
   [altstore.io](https://altstore.io), затем поставьте AltStore на iPhone.
   Компьютер и iPhone должны быть в одной сети Wi-Fi.
2. **Скачайте файл** — так же, как в способе 1, шаги 2–3.
3. **Откройте его через AltStore.** Нажмите на файл → «Поделиться» →
   «Скопировать в AltStore». Либо в самом AltStore: **My Apps** → **+** →
   выберите файл.
4. **Установите.** AltStore подпишет приложение вашим Apple ID.
5. **Подтвердите доверие**, как в способе 1, шаг 6.

## Какой способ выбрать

| | iLoader | AltStore |
|---|---|---|
| Нужен компьютер | нет | да, для установки и продления |
| Сложность настройки | ниже | выше |
| Продление подписи | вручную | **Refresh**, в том числе автоматически |

Оба способа ставят одно и то же приложение и одинаково безопасны: подпись
делается вашим собственным Apple ID на вашем устройстве.

## Частые вопросы

**Файл не скачивается, а открывается предпросмотром**
Зажмите кнопку «Download .ipa» и выберите «Скачать связанный файл» — Safari
сохранит его в «Файлы».

**Скачал файл, но иконки на «Домой» нет**
Так и должно быть — сам по себе `.ipa` ничего не устанавливает. Его нужно
подписать через iLoader или AltStore, тогда иконка и появится.

**Просит войти в Apple ID**
Это нормально и требуется обоими способами: так приложение подписывается
лично для вас при установке и при каждом продлении.

**Пишет «Ненадёжный разработчик»**
Настройки → Основные → VPN и управление устройством → выберите профиль →
«Доверять».

**Приложение перестало открываться через неделю**
Это ограничение бесплатного Apple ID — подпись действует 7 дней, и оно
одинаково для обоих способов. В AltStore нажмите **Refresh**, в iLoader
переустановите приложение тем же файлом. Данные при этом остаются на месте.

**Можно ли поставить обоими способами сразу**
Нет, выберите один. Это одно и то же приложение с одним идентификатором:
установка вторым способом просто заменит первое.

## Приватность

NijatMessenger использует сквозное шифрование для сообщений и звонков, не
показывает рекламу и не собирает данные о вас.
